# 미활동 회원 강등 절차

1년 동안 글을 쓰지 않은 1GLASS~4GLASS 회원을 비지터로 내리고, 다시 글을 쓴 회원을 원래 등급으로 되돌리는 운영 절차다. 스크립트는 `scripts/member-demotion/`에 있다.

## 기준

- **대상 등급**: 1GLASS~4GLASS. 5GLASS·스태프는 제외.
- **활동**: 수집 DB(`whisky_manager_collection`)에 들어 있는 게시판의 **글**만 센다. 댓글은 세지 않는다. 가입인사·출석부·회원 평가 같은 옛 게시판이나 인사 게시판은 수집하지 않으며, 활동 판단에서도 일부러 뺀다.
- **기간**: KST 날짜 기준, 시작일·종료일 포함.
- **가입 1년 미만 제외**: 기간 시작일 이후에 가입한 회원은 대상이 아니다.
- **현재 등급은 스튜디오에서 읽는다**: 수집 DB의 회원 등급은 강등을 반영하지 않을 수 있으므로, 대상 등급 판정은 스튜디오 회원 목록 API로 한다. 이미 비지터인 회원은 자연히 빠진다.
- **강등 사유**: `1년 글 미작성, 새글 작성 후 재등업 가능` (스튜디오 제한 25자).
- 재등업은 자동이 아니다. 모든 GLASS 등급은 등업게시판 수동 승인이다.

## 준비

1. **글 수집이 기간 끝까지 되었는지** 확인한다. `build_targets.py`가 처음에 기간 안 수집 범위를 출력한다 — 마지막 글 시각이 종료일 밤에 닿아 있어야 한다.
2. **Aside 브라우저**를 켜고 네이버에 로그인한 뒤 `https://studio.cafe.naver.com/@<cafeId>/member/list` 탭을 하나 열어 둔다. 스크립트는 `~/.local/bin/aside repl`로 이 탭과 로그인 세션을 쓴다.
3. `config/local.json`에 `cafeId`가 있어야 한다.

## 1. 대상 수집

```bash
python3 scripts/member-demotion/build_targets.py --start 2025-09-23 --end 2026-09-23 --exclude-csv ~/Documents/이전_대상.csv --out-dir ~/Documents
```

- `--exclude-csv`는 이전에 처리한 명단이다(여러 번 줄 수 있음). 그 명단의 회원은 이번 대상에서 빠지고 제외 파일에 `기존 명단 중복`으로 남는다.
- 결과
  - `inactive_<시작>_<종료>_대상.csv` — 멤버 태그, 멤버 키, 닉네임, 등급, 가입일, 기간 이전 마지막 글, 기간 이전 글 수
  - `inactive_<시작>_<종료>_제외.csv` — 위 열 + 제외 사유(가입 1년 미만 / 기존 명단 중복)
- 스튜디오 목록은 한 번에 5000명까지만 보이므로, 5000명이 넘는 등급은 가입일 오름차순·내림차순 양쪽에서 읽어 합친다.

## 2. 강등 실행

먼저 드라이런으로 목록에서 대상이 잡히는지 본다(체크·변경 없음).

```bash
python3 scripts/member-demotion/demote.py --targets ~/Documents/inactive_2025-09-23_2026-09-23_대상.csv --dry-run
```

실행:

```bash
python3 scripts/member-demotion/demote.py --targets ~/Documents/inactive_2025-09-23_2026-09-23_대상.csv
```

동작:

- 4GLASS → 3GLASS → 2GLASS → 1GLASS 순서.
- 등급 필터 + 최근 방문일 오름차순 목록을 250명씩 1페이지부터 연다. 페이지에 있는 대상(최대 100명)을 체크 → `등급 변경` → 비지터 확인 → 사유 입력 → `확인`.
- 강등된 행은 목록에서 빠지고 뒤 행이 올라오므로, 대상이 없어질 때까지 같은 페이지를 다시 읽고 나서 다음 페이지로 간다.
- `조정 멤버가 N명 포함되어 있습니다` 확인창과 `등급이 변경되었습니다` 알림은 자동으로 `확인`한다. 그 밖의 알림, 등급 선택이 비지터가 아닌 경우 등은 즉시 멈춘다(`studio stopped: …`).
- 배치마다 `<대상>.progress.jsonl`에 기록한다. 중간에 멈추면 같은 명령을 다시 실행하면 기록된 회원은 건너뛴다. 오래된 ref 같은 일시 오류는 등급별로 3번까지 자동 재시도한다.
- 끝에 등급별 `STATUS <등급>: demoted=N not_found=M`을 찍는다. `not_found` 회원은 목록에 없던 회원(다른 운영진이 이미 변경 등)이므로 멤버 태그로 따로 확인한다.

## 3. 복구 명단

강등 뒤 다시 글을 쓴 회원을 찾는다. 스튜디오에서 지금도 비지터인 회원만 남긴다. 복구는 운영자가 직접 한다.

```bash
python3 scripts/member-demotion/restore_candidates.py --targets ~/Documents/inactive_2025-09-23_2026-09-23_대상.csv --since 2026-09-24 --out ~/Documents/강등_복구대상.csv
```

- `--targets`는 여러 번 줄 수 있다. `멤버 키` 열이 없는 예전 명단은 스튜디오에서 태그마다 키를 찾아 오므로 오래 걸린다(수천 명이면 수 분).
- 결과 열: 멤버 태그, 닉네임, 되돌릴 등급, 현재 등급, 사유(`<날짜> 이후 글 N건 (게시판)`).

## 주의

- 강등은 되돌리기 번거롭다. 대상 파일을 먼저 훑어보고, 드라이런으로 확인한 뒤 실행한다.
- 운영진이 손으로 등급을 바꾸기도 하므로, 누가 바꿨는지는 스튜디오 멤버 상세의 등급 변경 이력으로 확인한다.
- 스튜디오 화면 구조(체크박스·버튼 이름)가 바뀌면 `demote.py`의 페이지 스크립트가 `no_grade_change_button`, `dialog_not_open` 등으로 멈춘다. 이때는 화면을 보고 선택자를 고친다.
